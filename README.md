 Gestión de Clientes en C#

## Descripción

Este proyecto es una aplicación de consola desarrollada en C# que permite registrar clientes, analizar sus compras y clasificarlos automáticamente según el monto acumulado.

El sistema fue creado como práctica para fortalecer fundamentos de programación y lógica aplicada a casos reales.

---

## Funcionalidades

- Registro de múltiples clientes
- Almacenamiento de:
  - Nombre
  - Correo electrónico
  - Monto de compras
- Validación básica de correo electrónico
- Clasificación automática de clientes:
  - Regular
  - Frecuente
  - VIP
- Cálculo de:
  - Monto total acumulado
  - Promedio de compras
  - Cantidad de clientes VIP
- Búsqueda de clientes por nombre
